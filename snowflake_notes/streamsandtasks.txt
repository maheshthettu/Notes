Task :

Task is a snowflake built-in sceduling object generally used to orchestrate the SQL statements
Based on time and its dependency .

Based on trigger condition tasks are two type 
1.Time based 
2.Event Based 

CREATE OR REPLACE TASK TASK_NAME 
WAREHOUSE= COMPUTE_WH
SCHEDULE = ' 2 mins'
AS 
INSERT INTO TARGET 
SELECT * FROM SOURCE 
;


CREATE OR REPLACE TASK TASK_NAME 
WAREHOUSE= COMPUTE_WH
SCHEDULE = ' 2 mins'
WHEN SYSTEM$STREAM_HAS_DATA('stream_name')
AS 
INSERT INTO TARGET 
SELECT * FROM SOURCE 
;
