# Airflow

Apache Airflow is an open-source orchestration tool generally used to schedule, monitor and manage Data engineering workflows or pipelines.

1. It has a Job sceduler that run your tasks by obligating their execution dependencies.
2. Workflows are written as code in the form of DAG(Direct Acyclic Graphs).
3. Since these are written in DAGs, So they became more dynamic, Managable,testable and collabarative.
4. By using Airflow we can communicate with any third party python API and can execute an endless verity of task irrespctive of their language.

#### Features :
1. Rich UI
2. Rich Command Line interface 
3. Transferring data between tasks 
4. performing backups
5. Automate devops
6. Machine learning jobs and more ....
